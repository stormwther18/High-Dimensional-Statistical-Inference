## 复现与独立核验

仅复验现有数据，需要 Python 3.10+ 和 NumPy，实际运行环境为 Python 3.12.14 / NumPy 2.3.5。在本目录运行：

```bash
python3 verify_results.py
```

重新模拟同一设计并核验（会替换本目录内本次实验的同名数据、配置和核验结果）：

```bash
python3 run_experiment.py
python3 verify_results.py
```

实验函数在本目录优先寻找附带的 `A1_ridge_reproduction.py`，随后查找父目录；导入不触发旧主程序。源文件及数据哈希与配置逐一核对。不同 BLAS/数值环境可能产生最后几位浮点差异；重新运行实验会记录当前环境与新数据哈希。

如需从数据重新生成正式源文件，依次执行（只需Python标准库）：

```bash
python3 make_latex_figures.py
python3 build_latex_report.py
```

生成的主 `.tex` 写入 `../latex/`。随后以 XeLaTeX 连续编译两遍（也可直接在LaTeX编辑器中编译）；所需宏包为常见的 CTeX、amsmath、newtxtext/newtxmath、PGFPlots 等。主源文件已内联全部图表坐标，不依赖外部CSV、图片或其他 `.tex` 片段，复制单个源文件即可编译。中文采用Fandol宋体，西文及数学采用Times风格字体。实验数据和数值结论沿用本次已核验输出。

## 关键计算口径

- 岭目标为 `||y−Xw||²/n + λ||w||²`，即线性方程惩罚为 `nλ`。
- BinaryTree深度4，n=p=15；Exponential rate=1，n=p=20，中点分位谱不额外强制均值为1。两模型的实际 γ=p/n 均为1。
- α²=1、噪声方差1；测试响应与训练响应使用同次真实系数w，测试特征和噪声与训练独立。
- 六个独立随机数流为 `SeedSequence([master_seed, model_id])`，模型编号1/2，种子2026102201/02/03。
- 公共网格为 `unique(linspace(0.1,sqrt(10),61)**2 ∪ {1})`，共62点。
- `test_mse` 是实际独立测试集MSE；`population_risk` 是 `1+(w_hat−w)'Σ(w_hat−w)`；`conditional_risk` 是给定X、对w和训练噪声积分后的精确风险；`theory` 是使用有限总体谱H_p的确定性等价。
- 固定λ下，SE为R个重复MSE的样本标准差除以√R；点态近似95%区间为均值±1.96SE，未声称整条曲线同时覆盖。
- 理论差值为测试均值减理论；观测最优λ为同组全网格测试均值的argmin；相对偏离为 `abs(观测最优λ−1)`；确定性风险增量为 `R(观测最优λ)−R(1)`。
- `test_minus_conditional` 使用同次重复的配对差，其SE为配对差样本标准差/√R。`paired_difference_se` 与 `test_minus_conditional_se` 是兼容列名，数值相同。
- `conditional_mean−theory` 可估计有限样本平均风险相对理论近似的差异，但仍有X的抽样误差。六组精确条件风险曲线的最优点均为1，可由方法审查中的导数式直接说明。

## 已完成的核验

`verification.json` 记录186,000行唯一组合、496行扫描汇总、8行最优表（两者均含合并结果）的独立复算；汇总最大绝对差1.64e−14。另重放每组首个重复的所有λ，与372次直接矩阵求解比较，条件风险最大差2.32e−13。既有一般协方差公式、单位谱还原、总体谱和零空间核验均通过。

另一个独立审查过程直接用标准库 `statistics` 复算六组表，不调用实验汇总函数，结果一致。详细分析见 `methods_review.md`。

本次固定配置的风险曲线与最优区域复验已完成。理论风险不是有限样本精确真值，观测最优参数也不是经过独立验证集选择后的性能结论。
