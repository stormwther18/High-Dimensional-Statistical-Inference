# A1 高维岭回归预测风险复现

本项目使用 Python：已有基础代码采用 Python，NumPy 足以完成矩阵计算和完整模拟。图表坐标写入原有 LaTeX 文稿，由 PGFPlots 与整篇文稿一同编译，因此不依赖 Matplotlib，也不使用图片替代公式。

正文按三部分组织：Introduction（一段引言）、理论基础、实验复现。本轮补齐 BinaryTree、Exponential 两种原文模型的 Python 实验和 TeX 理论说明，未运行 Python 或编译 LaTeX。现有四图和数值仍是此前的单位协方差结果；新增两图和结果表需本地运行后生成。程序只更新各自标记的实验区块，保持三部分结构。

## 原文模型如何补齐

模型构造对照作者仓库 https://github.com/dobriban/high-dim-risk-experiments ，核对版本为 `d551acd2b3ce283e8ddf3885de4d9fc60dddd766`。

- BinaryTree：按 `ridge_hier_sim.m`，深度 d 的维数为 p=2^d−1。特征值 2^j 的重数为 2^(d−j)，最后归一化至平均特征值为 1。默认 d=4、p=15，n=floor(p/目标 gamma)。论文图注写 p=2^4，与公开代码有差异；正文如实说明，理论使用实际 p/n。
- Exponential：按 `ridge_exp_sim.m`，特征值为指数分布的中点分位数 −log((i−0.5)/p)/rate。默认 n=20、rate=1，p=floor(n×目标 gamma)，不额外归一化有限维谱均值。
- 与作者实现一样，在协方差特征基下令 Sigma=diag(t)，X=Z sqrt(Sigma)。这是旋转不变模型的谱等价实现，保留预测风险分布。BinaryTree 不是二项分布，Exponential 不是把原始特征直接生成为指数随机变量；Z、系数和噪声均为高斯变量。

通用理论使用有限总体谱 H_p 求解负实轴伴随 Stieltjes 方程，并以解析导数计算风险。这是一般协方差确定性等价，不能解释为有限样本精确风险。精确条件风险另用 Sigma 加权迹公式计算，过参数时补齐加权零空间项；拟合后的总体风险也采用 Sigma 加权系数误差。

新实验默认每组 500 次训练重复、每次 100 个独立测试点，与作者公开模拟函数一致；正则网格默认 50 点并加入实际理论最优点。同次重复内不同 lambda 共享训练与测试数据，原 MATLAB 实现则逐个 lambda 重抽样，因此不要求随机曲线逐点相同。

## 运行

需要 Python 3.10 或以上与 NumPy。

目前已有单位协方差结果，建议先只补原文的两种模型：

```bash
python3 A1_ridge_reproduction.py --experiments paper
```

该命令保留已有四图及单位协方差数据，只更新新增实验区块并生成相关 CSV、配置与摘要。之后编译同一 TeX 文件两次即可看到新增图表。

完整重跑三个模型（默认 all）：

```bash
python3 A1_ridge_reproduction.py
```

仅重跑单位协方差：

```bash
python3 A1_ridge_reproduction.py --experiments identity
```

仅执行实现核验，不执行扫描实验或更新文稿：

```bash
python3 A1_ridge_reproduction.py --check-only
```

新增实验快速试跑（输出会更新为这次较小配置，不宜作为正式结果）：

```bash
python3 A1_ridge_reproduction.py --experiments paper --paper-repetitions 20 --paper-test-size 100 --paper-lambda-points 15
```

增加样本规模和重复数：

```bash
python3 A1_ridge_reproduction.py --experiments paper --tree-depth 6 --exp-n 120 --paper-repetitions 500 --paper-test-size 2000
```

程序每次输出到脚本所在文件夹；当前模式对应的同名 CSV、配置和结果摘要会更新，LaTeX 文稿中相应标记的结果区块也随之更新。Introduction、理论及另一类实验区块保留。增加树深度或 Exponential 样本量属于规模扩展，文稿会记录实际配置。

若系统 Python 没有 NumPy，可使用当前电脑已有的完整路径：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
/Users/liruiyu/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 A1_ridge_reproduction.py --experiments paper
```

单线程设置用于避免小矩阵计算时线程调度的额外开销，不改变统计设定。

## 数据含义与实验口径

基础模型为 Sigma=I、alpha²=1、噪声方差=1，岭惩罚采用 `n*lambda`。默认训练样本量为 120，每组 100 次独立重复，每次独立测试集大小为 2000。每次重复重新生成训练特征、真实系数和噪声，并拟合岭回归；同一次重复内各个 lambda 共享训练与测试样本。测试响应始终使用训练时的同一真实系数。

新增模型 CSV 延续这些风险字段，但 `population_mean` 改用 1+(w_hat−w)' Sigma (w_hat−w)，`conditional_mean` 改用一般协方差加权谱公式。`theory` 是 H_p 确定性等价风险；`model`、`gamma_target`、`population_mean_eigenvalue` 分别记录谱模型、目标比值和平均总体特征值。新增核验包含：通用理论还原单位协方差闭式公式、加权谱与直接迹一致、双空间秩亏及零空间项、有限条件风险最优点、固定 X 的系数和噪声模拟。它们会在你本地运行时执行，本轮未声称通过运行核验。

两个主实验 CSV 的关键字段：

| 字段 | 含义 |
|---|---|
| `gamma` | 实际 p/n，已考虑 p 取整 |
| `lambda_` | 论文归一化下的正则参数 |
| `theory` | 高维渐近总预测风险，包含噪声底座 1 |
| `conditional_mean` | 给定 X、平均系数及训练噪声后的精确条件风险，再对 X 取平均 |
| `conditional_se` | 条件风险重复均值的标准误 |
| `population_mean` | 每次实际拟合后，在 Sigma=I 下计算 1+系数误差平方范数，再取重复均值 |
| `population_se` | 上一项的标准误 |
| `test_mean` | 独立有限测试集 MSE 的重复均值 |
| `test_se` | 测试 MSE 重复均值的标准误 |
| `test_ci_low`、`test_ci_high` | 均值的近似点态 95% 区间 |
| `paired_test_minus_conditional` | 同一重复内测试误差减精确条件风险的均值 |
| `paired_difference_se` | 该配对差值均值的标准误 |
| `absolute_test_theory_gap` | 测试均值与理论值之差的绝对值 |

误差区间只针对重复实验的均值，不是整条曲线的同时置信带。理论和有限样本风险不要求精确相等，有限测试集曲线的最低点也不要求逐次位于理论最优点。

## 实现核验

程序在正式模拟前完成下列核验，并在失败时停止：

1. 三个理论最优风险的解析核对值。
2. 强正则、无正则和插值附近的理论边界。
3. 欠参数、等参数、过参数三个设置下，谱拟合与直接线性方程求解的一致性。
4. 条件风险的谱公式与矩阵迹公式的一致性，包含零特征值偏差。
5. 精确有限样本条件风险的最小点。
6. 固定训练特征后，4000 次系数与训练噪声重复的平均拟合总体风险，与精确条件风险的匹配。

所有实验使用固定随机种子；lambda 扫描、gamma 扫描、样本规模检查使用独立随机数流。图表在 LaTeX 中绘制，CSV 保留误差数据用于后续检查。
